# Kullanım Talimatı

Her GitHub repository'si için:

1. Bu paketteki `LICENSE` dosyasını repository'nin ana dizinine yükleyin.
2. `DISCLAIMER.md` dosyasını ana dizine yükleyin.
3. `README_TEMPLATE.md` dosyasını açın, köşeli parantez içindeki alanları düzenleyin ve dosya adını `README.md` yapın.
4. `CITATION_TEMPLATE.cff` dosyasındaki proje adı, sürüm, tarih, repository ve GitHub Pages adreslerini düzenleyin; ardından dosya adını `CITATION.cff` yapın.
5. İsterseniz `FOOTER_SNIPPET.html` içeriğini uygulamanızın `index.html` dosyasındaki en alt bölüme ekleyin.
6. GitHub ana sayfasında lisansın ve mümkünse “Cite this repository” seçeneğinin göründüğünü kontrol edin.

Not: LICENSE dosyasındaki telif sahibi veya geliştirici yapısı proje bazında farklıysa ilgili satırı düzenleyin.
